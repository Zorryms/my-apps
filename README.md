# Моя бібліотека
Особиста бібліотека українською: обкладинки, три полиці, пошук, оцінки, нотатки, посилання, кошик із відновленням і резервні копії JSON.

Сайт працює на GitHub Pages; книги та стиснуті обкладинки зберігаються в Supabase. Вхід через email і пароль. Сесія запам'ятовується на цьому пристрої. На чужому пристрої потрібно вийти.

## Дані та доступ
- Серверні правила RLS дозволяють читати, додавати й змінювати тільки книги поточного користувача.
- Пряме остаточне видалення через клієнт не дозволено. Кошик — це позначка в записі, книгу можна відновити.
- Без інтернету зміни не зберігаються; форма показує помилку і лишається відкритою.
- Синхронізація відбувається під час входу, повернення у вкладку, натискання «Оновити» та кожні 45 секунд у відкритій бібліотеці.
- Одночасні зміни однієї книги з двох пристроїв: останнє збереження перезаписує попереднє. Перед редагуванням натисни «Оновити».
- Резервна копія містить книги та обкладинки. Відновлення додає відсутні книги, не перезаписує наявні. Книги з кошика резервної копії повертаються на полиці.
- Публічний ключ Supabase у config.js не є секретом. Secret/service_role key ніколи не можна додавати до сайту.
- Стару локальну нотатку можна відкрити через посилання внизу. Вона не синхронізується.

## Публікація
HTML/CSS/JS у корені main, GitHub Pages → main → / (root). При зміні файлів збільшуй версію CACHE у sw.js. config.js має містити URL проєкту та публічний (publishable/anon) ключ. Схема бази й обмеження мають бути застосовані до підключення сайту.
