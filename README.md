# My Apps — мініпрограма для телефона

Готова панель на HTML/CSS/JS, іконка, встановлення та офлайн-нотатка. Без залежностей і збірки.

## Опублікувати безплатно на GitHub Pages
1. Створи Public репозиторій `my-apps` на https://github.com/new.
2. Вибери Add file → Upload files. Завантаж усі файли цієї папки безпосередньо в корінь репозиторію. Не завантажуй ZIP замість файлів. Натисни Commit changes.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Дочекайся посилання https://ТВІЙ-ЛОГІН.github.io/my-apps/ і відкрий його на телефоні.
5. Android (Chrome): натисни «На головний екран» на сайті або меню ⋮ → «Встановити додаток» / «Додати на головний екран».
6. iPhone (Safari): «Поділитися» → «На Початковий екран».

Офлайн працює після першого повного завантаження через HTTPS. Просте відкриття index.html з диска дає лише попередній перегляд, без встановлення й офлайн-кешу.

GitHub Pages тут публічний: це не панель із приватним входом. Нотатки зберігаються локально в браузері; очищення даних сайту їх видалить. Синхронізації та резервних копій немає.

При оновленні файлів збільш версію CACHE у sw.js (v1 → v2), потім закрий старі вкладки програми та відкрий знову.

Документація: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
